# Navigation

Navigation components help users move through the application and understand where they are.
This includes app-level chrome (top bars) and menus.

- **App Bars** — persistent bars pinned to the top of a screen (`TopBar`, `NavBar`, `BackLinkTopBar`) used
  to show the current page/section and provide primary navigation actions.
- **DropDown** — a floating menu of selectable/actionable items, used for navigation menus or contextual
  actions triggered from a button.

If a component's main purpose is to move the user between views or sections, it belongs here rather than
in `Buttons` or `Input`.
