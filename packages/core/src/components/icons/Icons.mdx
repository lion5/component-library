# Icons

Purely visual, stateless SVG icon components (`IconArrowBack`, `IconCheck`, `IconTrash`, ...) plus the
generic `BaseIcon` wrapper used to build them. Icons are kept as their own category regardless of the
functional taxonomy used elsewhere, since there are many of them and they carry no behavior on their own.
