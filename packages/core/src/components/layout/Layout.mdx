# Layout

Layout components provide structural scaffolding for arranging content on a page — grids, columns,
sections, and headers/footers. They don't render domain data themselves; they arrange *other* components.

Examples: `LayoutOneColumn`, `LayoutTwoColumns`, `LayoutDynamicGrid`, `LayoutStack`, `LayoutSection`,
`LayoutSectionHeader`, `LayoutFormHeader`, `LayoutStepHeader`, `LayoutOptionHeader`, `LayoutBasicFooter`,
`PageLayoutOneColumn`.

If a component is reusable page/section scaffolding regardless of what content it contains, it belongs here.
